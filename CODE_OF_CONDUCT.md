# Código de conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) como código de conduta. Em resumo: trata todas as pessoas com respeito, assume boa fé e mantém a discussão construtiva.

Comportamentos abusivos podem ser comunicados ao responsável do repositório através das Issues ou por contacto direto.
